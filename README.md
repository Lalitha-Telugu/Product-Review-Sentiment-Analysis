# 🛒 Product Review Sentiment Analysis using NLP & Machine Learning

## 🚀 Project Overview

This project focuses on analysing customer product reviews using Natural Language Processing (NLP) and Machine Learning.

The system automatically classifies customer reviews into three sentiment categories:

- Positive
- Negative
- Neutral

The objective is to help e-commerce businesses understand customer opinions and improve customer satisfaction.

## 🔍 Project Workflow

1. Dataset Collection
2. Exploratory Data Analysis
3. Data Cleaning
4. Text Preprocessing
5. TF-IDF Feature Extraction
6. Train-Test Split
7. Machine Learning Model Training
8. Model Evaluation
9. Sentiment Prediction
10. Gradio Application Development

## 🤖 Machine Learning Algorithms

- Multinomial Naive Bayes
- Logistic Regression
- Linear Support Vector Machine (SVM)

## 📊 Model Performance

| Algorithm | Accuracy |
|---|---:|
| Multinomial Naive Bayes | 89.19% |
| Linear SVM | 87.84% |
| Logistic Regression | 81.49% |
